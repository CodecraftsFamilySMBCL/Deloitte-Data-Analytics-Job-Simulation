# Deloitte Australia – Data Analytics Virtual Internship (Forage)

## Overview
This repository contains the tasks, deliverables, and learning outcomes completed as part of the Deloitte Australia Data Analytics Virtual Internship Program offered through Forage.

The program provided hands-on experience in Data Analytics, Business Intelligence, and Forensic Technology through industry-simulated projects that replicate real-world consulting challenges faced by Deloitte professionals.

## Certificate
Successfully completed the Deloitte Australia Data Analytics Job Simulation on April 25, 2026.

## Project Objectives
- Analyze business datasets to identify trends and insights.
- Perform data cleaning and transformation.
- Develop data visualizations and dashboards.
- Support data-driven decision-making.
- Apply business intelligence and reporting techniques.
- Explore forensic technology concepts.
